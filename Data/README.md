# Data and scope

The Excel file contains Orders, Managers and Inventory worksheets. A separate traffic-accident CSV is bundled but is not used for the sales summaries. Source files remain unchanged.

The separate executive preview displays 2,703 customers, 6,455 orders, $8.952M sales and a 15% profit ratio, which do not reconcile to the included Orders sheet. Its source and filter scope are not recoverable from the files. The map value near $457,688 is a state-level figure, not the West regional total. No .twb/.twbx workbook or live dashboard link is included, so interactions, calculations and refresh behavior cannot be tested. The repository does not document upstream dataset provenance; filenames containing 2026 do not imply 2026 sales.
